# 🌤️ Weather Application

## 📌 Project Overview

This is a responsive Weather Application built using
HTML, CSS, and JavaScript.

The application allows users to check real-time weather
information for different locations. It displays
temperature, humidity, wind speed, weather forecasts,
and weather icons.

## 🚀 Features

- 🌡️ Current Temperature
- 💧 Humidity Information
- 💨 Wind Speed
- 🌦️ Weather Forecast
- 🔥 Minimum and Maximum Temperature
- 🌤️ Weather Icons
- 📍 Location-Based Weather Information
- 📱 Responsive Design
- 🔍 Search Weather by Location

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in your browser.
4. Search for a location to view weather information.

The purpose of this project is to create a
